# مرساة — Mersah Daily v1

دفتر يومي شخصي محلي للمذكرات والمهام والالتقاطات. لا حسابات، لا خادم، لا مزامنة، ولا build process.

## الملفات

- `index.html` — هيكل الواجهة والأنماط.
- `app.js` — منطق التطبيق وقاعدة IndexedDB.
- `sw.js` — التشغيل دون اتصال وتخزين ملفات التطبيق الأساسية.
- `manifest.webmanifest` — تعريف التطبيق القابل للتثبيت.
- `icons/` — مصدر الأيقونة المرفق ونسخ 180 و192 و512 و1024 بكسل.
- `TESTS.md` — قائمة تحقق تمنع رجوع السلوكيات المتفق عليها.

## ما ينفذه v1

- شاشة «اليوم»: اسم اليوم، التاريخ، إنجاز أهم المهام، توجّه اليوم، أهم ثلاث مهام، وسجل اليوم الزمني.
- توجّه اليوم يظهر كملخص مضغوط؛ الضغط عليه يفتح ورقة تحرير، وهو محفوظ وأرشيفي لكل تاريخ وبحد 180 حرفًا، ويمكن الرجوع إليه من «الأيام».
- أهم ثلاث مهام كروابط لإدخالات موجودة، مع منع المهمة الرابعة.
- زر التقاط عائم في كل الواجهات، افتراضيًا إلى اليمين وموضعه قابل للتغيير، مع مساحة سفلية تمنع حجب آخر المحتوى.
- التقاط نص أو صور أو الاثنين معًا، مع كاميرا ومكتبة صور ومعاينة قبل الحفظ.
- Enter يضيف سطرًا جديدًا في الالتقاط؛ الحفظ بالزر أو `Cmd/Ctrl + Enter`.
- ضغط الصور الكبيرة محليًا قبل الحفظ داخل IndexedDB.
- المسارات: للنظر، نفّذ، بانتظار، مرجع. الإدخالات الجديدة تبدأ في صندوق «غير مفرز» حتى توجيهها.
- أنواع الإدخال: مهمة، ملاحظة، فكرة، قرار، انعكاس.
- حالات التنفيذ: مفتوح، مكتمل، مغلق، محذوف.
- شاشة المسارات تعرض محددًا واحدًا للمسارات الأربعة، والأحدث أولًا داخل المسار المختار.
- بطاقات الإدخال تحمل شريطًا بلون المسار ورمزًا سريعًا: `◇` غير مفرز، `☑` نفّذ، `✦` للنظر، `◷` بانتظار، `▤` مرجع.
- الضغط على رمز المسار يفتح المسارات الأربعة للتغيير، ويبقى المسار متاحًا أيضًا في التحرير.
- وقت البطاقة مختصر بحسب السياق، والمواعيد نسبية، ونجمة أهم اليوم بلا تاريخ مكرر.
- إجراءات البطاقة رمزية مع أسماء وصول وتلميحات، بينما تبقى إيماءات السحب والضغط المطول مؤجلة لجولة مستقلة.
- رأس «اليوم» مضغوط ويعرض تقدم أهم المهام بثلاث دوائر بدل الكسر النصي.
- تحرير الإدخال مبسّط بلا حقول النوع أو الحالة أو السياق/المشروع أو الشخص المرتبط.
- الإعدادات تبويب خامس في شريط التنقل السفلي لسهولة الاستخدام بيد واحدة.
- شاشة الأيام مع آخر 30 يومًا أولًا وتفاصيل كل يوم.
- بحث عربي مطبع يشمل النص والسياق والشخص والمسار والتاريخ، مع مرشحات للمسار والفترة.
- تصدير JSON كامل يتضمن النصوص والصور وتوجهات الأيام والإعدادات، ويُقسّم تلقائيًا عند كثرة الصور.
- تصدير Markdown للقراءة، مع أسماء الصور دون تضمين bytes.
- استيراد JSON v1 واستيراد نسخ v0 القديمة ذات `cards/outcomes`.
- كل حزمة JSON تحمل معرّفًا وأرقام أجزاء؛ الاستيراد يرفض الجزء الناقص أو المكرر أو المختلف والصور بلا إدخالات قبل كتابة البيانات.
- الاستيراد يدعم حتى 200 ألف إدخال و200 ألف مرفق ضمن حدود الحجم، ويكتب السجلات على دفعات من 1000.
- خرائط ذاكرة للتاريخ والمسار والمهام العليا والمرفقات تمنع إعادة مسح كامل القاعدة عند فتح «الأيام» أو «المسارات».
- الإعدادات تعرض الاستخدام والحصة والمتاح، وتنبّه عند غياب نسخة مؤكدة أو مرور سبعة أيام عليها.
- اقتراح هجرة v0 المحلية عند توفر `indexedDB.databases()`.
- محذوفات تحفظ 7 أيام ثم تنظف تلقائيًا.

## قاعدة البيانات

- قاعدة v1: `mersah-daily`.
- مخازن IndexedDB: `entries`, `attachments`, `daily`, `settings`.
- قاعدة v0 القديمة، إن وجدت، تبقى باسم `mersah-db` ولا تُحذف تلقائيًا.

## التشغيل المحلي للاختبار

لا تفتح `index.html` بالنقر المباشر؛ Service Worker وIndexedDB يعملان بثبات عبر HTTP/HTTPS.

```bash
python3 -m http.server 8080
```

ثم افتح:

```text
http://localhost:8080
```

## النشر على GitHub Pages

1. ارفع محتويات هذا المجلد إلى جذر المستودع مع `icons`.
2. ارفع `index.html` و`app.js` و`sw.js` معًا دائمًا.
3. فعّل Pages من إعدادات المستودع على الفرع `main` والمجلد `/`.
4. بعد النشر افتح الرابط من Safari وثبّت التطبيق على الشاشة الرئيسية.

> رابط GitHub Pages قد يكون عامًا حتى لو كان المستودع خاصًا. بيانات مرساة لا تُرفع إلى GitHub؛ تبقى في IndexedDB على جهاز المستخدم.

## تحديثات Service Worker

Service Worker يخدم النسخة المخزنة أولًا. عند تعديل `index.html` أو `app.js`:

1. ارفع رقم `CACHE_NAME` في `sw.js`.
2. ارفع `index.html`, `app.js`, `sw.js` معًا.
3. أغلق تطبيق iPhone وافتحه مرتين؛ الأولى تثبت التحديث والثانية تعرضه.

## iPhone و iCloud

- خيار «حزمة iCloud» ينشئ JSON كاملًا وMarkdown ويفتح نافذة المشاركة. قد يقسم JSON إلى أجزاء لحماية ذاكرة iPhone.
- عند وجود أجزاء متعددة، اخترها كلها معًا عند الاستيراد.
- على iPhone اختر Files ثم iCloud Drive أو On My iPhone.
- تطبيقات الويب لا تستطيع إنشاء مجلد داخل Files أو iCloud تلقائيًا، ولا تملك صلاحية الكتابة المستمرة إلى ملف هناك.
- JSON الكامل يحتوي بياناتك وصورك بنص/بيانات صريحة غير مشفرة. حفظه في iCloud يعني أن النسخة خرجت من المحلية الصرفة إلى سحابة Apple.

## ملاحظات أمنية

- CSP: `default-src 'self'` و`script-src 'self'`، ولا توجد مكتبات خارجية.
- التطبيق لا يرسل النصوص أو الصور لأي خادم.
- `Permissions-Policy` يوقف صلاحيات غير مستخدمة مثل الموقع والدفع والمستشعرات.
- الصور تحفظ كـ Blob داخل IndexedDB وتصدر Base64 في أجزاء محدودة الحجم بدل بناء سلسلة ضخمة واحدة.
- الاستيراد يحد الحجم وعدد السجلات ويطبع الحقول قبل الدمج.
- بدء تنزيل من المتصفح لا يُسجّل كنسخة مؤكدة؛ نجاح نافذة المشاركة هو الذي يحدّث تاريخ النسخ المؤكد.
- لا توجد حماية بكلمة مرور داخل v1؛ أي شخص يملك الجهاز والمتصفح يستطيع الوصول للبيانات المحلية.

## حدود v1

- لا مزامنة سحابية ولا حسابات مستخدمين.
- لا OCR ولا فهم تلقائي للصور.
- لا تكامل مباشر مع Things أو Google Calendar.
- لا تسجيل صوتي أو تفريغ تلقائي.
- حذف بيانات الموقع أو التطبيق قد يحذف البيانات المحلية.

## مقياس اختبار 14 يومًا

- استخدام مرساة في 12 يومًا على الأقل من 14.
- 80% من الالتقاطات اليومية تدخل مرساة أولًا.
- وسيط الالتقاط النصي أقل من 10 ثوانٍ.
- تحديد أهم ثلاث مهام في 10 أيام على الأقل.
- صفر مهمة مهمة ضاعت لأنها بقيت في «غير مفرز» أكثر من 72 ساعة.
- مراجعة «بانتظار» مرتين أسبوعيًا على الأقل.
- استرجاع عنصر معروف خلال أقل من 30 ثانية.
