# مرساة — Mersah v0

تطبيق شخصي محلي للالتقاط السريع والمراجعة الأسبوعية. لا حسابات، لا خادم، لا مزامنة، ولا build process.

## الملفات

- `index.html` — الواجهة والمنطق والتخزين.
- `sw.js` — التشغيل دون اتصال وتخزين ملفات التطبيق.
- `manifest.webmanifest` — تعريف التطبيق القابل للتثبيت.
- `icons/` — أيقونات 180 و192 و512 بكسل.

## ما ينفذه v0

- التقاط نصي مباشر: نص + Enter، دون تصنيف، مع تراجع سريع بعد الحفظ.
- الوارد، هذا الأسبوع، الأرشيف.
- «لاحقًا» كقسم مطوي داخل الوارد.
- تصفية يومية داخل الوارد للعناصر غير المشاهدة.
- مراجعة أسبوعية عنصرًا عنصرًا.
- ثلاث نتائج أسبوعية كحد أقصى.
- ترحيل عناصر الأسبوع السابق يدويًا.
- أرشفة العناصر غير المثبّتة والخاملة في «لاحقًا» بعد 30 يومًا من آخر تفاعل، عند بدء المراجعة الأسبوعية فقط، مع تراجع.
- بحث فوري يشمل كل الحالات مع تطبيع عربي وتوحيد الأرقام العربية والهندية واللاتينية.
- سياق حر مع اقتراح المفردات الموجودة وتوحيد المتطابق منها.
- `dir="auto"` لكل محتوى عربي/إنجليزي مختلط.
- تخزين محلي في IndexedDB وطلب `navigator.storage.persist()`.
- تصدير JSON للاستعادة الكاملة وMarkdown مناسب لـ Obsidian، مع إظهار عمر آخر نسخة احتياطية.
- استيراد JSON بالدمج حسب المعرّف؛ السجل الأحدث في `updatedAt` يفوز دون مسح البيانات الحالية.
- تثبيت عناصر «لاحقًا» لمنع التحلّل التلقائي.
- محذوفات تُفرغ تلقائيًا بعد 7 أيام.

## النشر على GitHub Pages — 6 خطوات

1. أنشئ مستودعًا جديدًا في GitHub، مثل `mersah`. عند استخدام الطرفية نفّذ `git init` داخل هذا المجلد أولًا؛ ويمكن بدلًا من ذلك رفع الملفات من واجهة GitHub مباشرة.
2. ارفع محتويات هذا المجلد إلى جذر المستودع، مع الحفاظ على مجلد `icons`.
3. افتح `Settings` في المستودع، ثم `Pages` ضمن `Code and automation`.
4. في `Build and deployment` اختر `Deploy from a branch`.
5. اختر فرع `main` والمجلد `/ (root)` ثم اضغط `Save`.
6. بعد اكتمال النشر، افتح الرابط الذي يظهر في صفحة `Pages`.

> ملاحظة خصوصية: رابط GitHub Pages قد يكون عامًا حتى لو كان المستودع خاصًا. بيانات مرساة لا تُرفع إلى GitHub؛ تبقى داخل IndexedDB على الجهاز. لا تضف مفاتيح API أو أسرارًا إلى الملفات.

## التثبيت على iPhone

1. افتح رابط التطبيق في Safari.
2. اضغط زر المشاركة.
3. اختر `Add to Home Screen` / `إضافة إلى الشاشة الرئيسية`.
4. فعّل `Open as Web App` إن ظهر الخيار، ثم اضغط إضافة.
5. افتح مرساة من الأيقونة المثبتة، واجعل هذه النسخة وحدها مصدر الحقيقة خلال اختبار 14 يومًا.
6. من `•••` داخل التطبيق اطلب التخزين الدائم وصدّر JSON بعد كل مراجعة أسبوعية.

## التشغيل المحلي للاختبار

لا تفتح `index.html` بالنقر المباشر؛ Service Worker وIndexedDB يعملان بصورة موثوقة عبر HTTP/HTTPS.

من داخل المجلد:

```bash
python3 -m http.server 8080
```

ثم افتح:

```text
http://localhost:8080
```

## النسخ الاحتياطي

- `JSON كامل`: النسخة الوحيدة المصممة للاستعادة. الاستيراد يدمج السجلات ولا يمسح العناصر غير الموجودة في الملف.
- `Markdown`: نسخة قراءة ومعرفة لضمها إلى Obsidian، وليست بديلًا عن JSON.
- IndexedDB تخزين محلي، وليس نسخة احتياطية مستقلة.

## حدود v0

- لا مزامنة بين الآيفون والماك.
- حذف بيانات الموقع أو التطبيق قد يحذف البيانات المحلية.
- الإملاء الصوتي يعتمد على زر الميكروفون في لوحة مفاتيح iOS؛ لا توجد خدمة تحويل صوت داخل التطبيق.
- الأسبوع يبدأ يوم الاثنين وفق وقت الجهاز.

## مسار v1 إذا ثبتت الحاجة إلى التحرير من الماك

المسار المحجوز: `Cloudflare Worker` + `KV`، مستخدم واحد، رمز مشترك، وLast-Write-Wins كبداية. لا يُنفذ قبل ظهور حاجة فعلية خلال تجربة v0، لأن المزامنة تضيف مصادقة وتعارضات ونسخًا احتياطية ومسؤولية أمنية.

قبل تنفيذ v1، أضف حقولًا صريحة لكل سجل:

- `revision`
- `deviceId`
- `syncedAt`
- `tombstone`

ولا تعتمد على `updatedAt` وحده لحل الحذف والتعارضات.
